# JXR Constructors, Inc. — Website Redesign

Working folder for the site redesign project.

## Folder structure

- `assets/logo/` — drop the JXR logo file(s) here (the black/blue/white circular monogram)
- `assets/projects/` — drop project photos here, ideally one subfolder per project, e.g.:
  - `assets/projects/va-san-diego-orpa/`
  - `assets/projects/sdia-terminal-2/`
  - `assets/projects/va-long-beach-rffvb/`
  - `assets/projects/va-loma-linda-4swbr/`
  - `assets/projects/va-los-angeles-canteen/`
  - `assets/projects/navfac-miramar/`
  - `assets/projects/va-san-diego-massu/`
- `content/site-copy.md` — all extracted copy from the live site (source of truth for text)
- `content/brand-notes.md` — palette, type, and design direction notes
